# Приют и передача животных в семью

Лабораторная работа № 4. Продолжение лабораторной № 3.
Проект на Java 21, Spring Boot и PostgreSQL. Добавлена защита API с помощью Spring Security.

## Что добавлено

- Вход по логину и паролю через HTTP Basic Auth.
- Регистрация с проверкой сложности пароля и уникальности логина и email.
- Хранение паролей в виде BCrypt-хешей.
- CSRF-защита запросов, изменяющих данные.
- Роли USER и ADMIN.
- Блокировка входа для пользователей с enabled=false.

## Запуск

1. Запустить PostgreSQL. База shelter_db и настройки подключения остались из лабораторной № 3.
2. Открыть pom.xml в IntelliJ IDEA и запустить ShelterApplication.
3. Приложение работает по адресу http://localhost:8080. Если старая версия запущена, сначала остановить её.

## Пользователи и права

При первом запуске создаётся администратор:
- Логин: admin
- Пароль: Admin12345!

При регистрации пользователь получает роль USER.

USER может просматривать животных и вольеры, подавать свои заявки и отзывать ожидающие заявки.
ADMIN управляет данными, одобряет заявки и оформляет передачу животных.

## Проверка

Выполнять запросы сверху вниз в requests.http, затем в business-operations.http.

В начале каждого файла есть запрос на получение CSRF-токена. Токен и номера созданных записей сохраняются автоматически.

Ожидаемый код ответа указан в названии каждого запроса. Есть примеры успешных действий и отказов в доступе.
